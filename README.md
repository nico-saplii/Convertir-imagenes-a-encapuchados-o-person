"# Conversor de Etiquetas YOLO Pose (Clase 0 - Person)" 
"" 
"Este script procesa imagenes utilizando YOLOv11 Pose para generar etiquetas automaticas en formato de texto." 
"" 
"## Instrucciones de uso:" 
"1. Coloca tus imagenes en la carpeta \`imagenes_convertir\`." 
"2. Asegarate de tener el archivo de pesos \`yolo11n-pose.pt\` en la misma carpeta." 
"3. Instala las dependencias necesarias: \`pip install ultralytics opencv-python\`" 
"4. Ejecuta el script que necesites, puede ser para encapuchados o personas normales.
"5. cuando entregue los labels ya tendras los vectores de cada imagen que pasaste, esto lo hace gracias al archivo yolo11n-pose.pt que esta en la carpeta, este toma la libreria preentrenada de yolo, asi se evitan errores en los vectores".
"6. Recuerda que debes equilibrar el % de imagenes, unas deben ir en train, otras en Valid, al igual que los labels".
